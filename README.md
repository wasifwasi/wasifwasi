### 👨‍💻 About Me

I am a BS Computer Science graduate and a passionate **Full-Stack Developer** with a strong foundation in the **MERN Stack**. I specialize in building scalable web applications and have a growing expertise in embedding **Artificial Intelligence** models into modern web interfaces.

* 🚀 **Core Stack:** React.js, Next.js, Node.js, MongoDB.
* 🤖 **AI/ML Interests:** OpenCV, TensorFlow, PyTorch, and Computer Vision.
* 🛠 **Architecture:** Microservices, REST APIs, and Docker containerization.
* 🧠 **Mindset:** Continuous learner focused on clean code and efficient problem-solving.
